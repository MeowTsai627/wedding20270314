# 婚禮備忘錄

以單一 HTML 檔案製作的婚禮代辦管理頁面，無需安裝或連線即可使用。使用最新版瀏覽器開啟 `index.html` 即可開始。

## 功能

- 透過燈箱表單新增婚禮待辦；點選待辦列可進入燈箱編輯，修改後儲存。點擊燈箱外會關閉表單並放棄未儲存的變更。
- 新增與編輯待辦可填寫廠商、預計完成日期及備註，內容會一併儲存在 Local Storage。
- 設為已完成時，需填寫完成日期、廠商、已付金額、付款人與尾款；付款總覽會統整所有已完成事項的已付、待付與總金額。
- 付款總覽以可點選的圓餅圖顯示已付與待付比例；點選圖例或圓餅圖可列出對應事項、廠商與金額（已付另顯示先支付者）。
- 付款總覽另依「誰先支付」顯示新郎與新娘各自的已付、待付總額，方便後續分帳。
- 左上角愛心按鈕可開啟選單，切換獨立的待辦清單／付款總覽頁面，並調整文字大小與背景樣式；偏好設定會保留在此瀏覽器。
- 可刪除待辦，並選擇場地佈置、婚紗造型、婚宴餐飲或其他事項分類。
- 工作狀態分為未開始、進行中、已完成。按下圓形勾選鈕即可標記完成，並自動記錄完成日期。
- 頁籤可切換「未完成」（包含未開始與進行中）、「已完成」及「全部」。開啟時預設顯示未完成。
- 新增事項的截止日預設為隔天；編輯時可以修改截止日及工作狀態。
- 可依預計完成日期、建立日期新到舊、建立日期舊到新排序。
- 顯示完成進度及婚禮倒數；可設定婚禮日期。
- 待辦與婚禮日期使用瀏覽器 Local Storage 儲存，重新開啟同一瀏覽器中的頁面後仍可使用。
- 日期顯示格式為 `YYYY/MM/DD`，例如 `2026/10/27`。

## 資料保存

資料只存在目前瀏覽器的 Local Storage。清除網站資料、改用其他瀏覽器或裝置，資料不會自動同步。若從舊版升級，頁面會嘗試讀取 `weddingMemoTasks_v1` 並轉換成新版資料格式。

## 檔案

- `index.html`：目前正式版本。
- `history/wedding_v01.html` 至 `history/wedding_v14.html`：歷次正式版備份。

目前正式檔以 `history/wedding_v03.html` 為基準，包含後續的 v1.3.1 表單欄位修正。
- `CHANGELOG.md`：版本更新紀錄。

每次更新前會先將當時的 `index.html` 完整備份至 `history/`，並同步更新版本號、本說明與版更紀錄。
